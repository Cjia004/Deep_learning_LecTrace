# EEG Tokenization — LecTrace

An execution-based course-project presentation with five selected inference states.

**[Open the presentation](https://cjia004.github.io/Deep_learning_LecTrace/)**

## Contents

- `website.zip`: static viewer generated by LecTrace 1.1.30; 59 execution steps and three charts.
- `EEG_Tokenization_LecTrace.zip`: complete Python source, original project model/config, one saved checkpoint, two held-out EEG windows, result tables, provenance manifest, verification record and Chinese speaker notes.
- `.github/workflows/pages.yml`: publishes the already-built viewer to GitHub Pages.

The five states are input normalization, patch embedding, temporal encoding, spatial encoding, and fusion/CLS classification. English explanations include Chinese presenter notes.

## Run or rebuild locally

Unzip the source archive, enter `lectrace_eeg`, and use Python 3.11+ with the project's PyTorch environment:

```sh
python -m pip install -r requirements.txt
python _verify.py
lectrace serve 01_eeg_tokenization.py
```

To regenerate the static site:
```sh
lectrace build 01_eeg_tokenization.py --output _site
```

Compress the **contents** of `_site` as `website.zip` at this repository root, then push the new archive. The deployment workflow does not retrain or reselect models.

## Experimental scope

This is EEG tokenization research. BDI grouping is a downstream evaluation task, not a clinical diagnosis. The walkthrough uses the frozen Step 10d ch4 TS control-task checkpoint (fold 0, seed 0). Its five intermediate outputs match the original forward implementation exactly in the verified environment.

The two windows were selected in recording order, before inference. One is misclassified; neither example is used to estimate population performance. Full-study BDI, control and probe results come from saved tables and are clearly separated.
